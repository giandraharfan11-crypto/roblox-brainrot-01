Brainrot Nusantara is a 3D Roblox brainrot game with an Indonesian flavour: absurd original meme creatures (a dancing catfish in a peci, a haunted traffic cone, a turbo snail on a skateboard, and a dozen more) walk a conveyor lane out of a swirling portal. Buy one with Money, carry it home on your head, and set it on a pad in your base, where it earns Money every second. Climb the rarity ladder (Common, Rare, Epic, Legendary, Mythic, Secret), roll Gold, Diamond and Rainbow mutations worth up to ten times the income, sell and rebirth for a permanent multiplier, lock your base for 60 seconds, steal from unlocked rivals, and when the GELOMBANG TSUNAMI warning sounds, sprint home before the wave sweeps the lane and takes whatever you are carrying.

## Run it

```sh
rojo build default.project.json --output game.rbxl
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `game.rbxl` in Roblox Studio and press Play: the whole world (bases, conveyor lane, portal and decorations) is built by the server scripts at start, so an empty place becomes the full game.

## Cara menjalankan di Roblox Studio (untuk pemilik akun)

1. Unduh `game.rbxl` dari repo ini (atau clone repo lalu jalankan `rojo build default.project.json --output game.rbxl`).
2. Buka `game.rbxl` di Roblox Studio, lalu **File → Publish to Roblox As…** untuk membuat experience baru dari akunmu.
3. Di Creator Dashboard / Game Settings: isi deskripsi (tempel **play code** make.fun di dalamnya), pilih genre, jawab pertanyaan konten, lalu setel experience ke **Public**.
4. Tekan **Play** di Studio untuk mencoba game, dan ambil 3–4 screenshot 16:9 (mis. 1280×720, maks 256 KiB per file).
5. Di Creator Dashboard: upload **Icon** (512×512) dan **Thumbnail** (thumbnail pertama = salah satu screenshot yang sama dengan yang ada di folder `screenshots/` repo ini), lalu tunggu sampai halaman experience menampilkan keduanya (lolos review Roblox).
6. Publish ulang place final ke experience yang sama, dan kirim balik **place_id** serta **universe_id** (dari link play dan alamat Creator Dashboard) supaya entri bisa di-submit.
